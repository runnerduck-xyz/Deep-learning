# Deep Learning

This repository contains beginner deep learning notebooks I made while practicing different machine learning tasks. The projects are small on purpose, so the notebooks can be opened, read, and rerun without a complicated setup.

The main folder is `beginner projects`. It includes notebooks for:

- tabular classification with PyTorch
- image classification with a convolutional neural network
- transfer learning with a pretrained image model
- audio classification using spectrogram features
- text classification with a small BERT model

## Project Structure

```text
beginner projects/
  001_RiceTypeClassification.ipynb
  002_AnimalFacesClassification.ipynb
  003_transfer_learning_01.ipynb
  004_Audio_Classification.ipynb
  005_Text_Classification.ipynb
```

Each notebook has short markdown notes and saved outputs. The goal is to show the basic process: load data, prepare it, build a model, train it, and check the result.

## Notes

This is a learning repository, not a production model repository. Some datasets use small sample files so the examples stay practical for GitHub and for normal laptop use.
